Política de Privacidade — ViralMax Publicador

Última atualização: 14 de novembro de 2026.

1. Quem usa o app

O ViralMax Publicador é uma ferramenta interna, usada apenas pelo dono dos canais do YouTube conectados a ela. Não há cadastro aberto ao público.

2. Dados que acessamos

Com a autorização dada no login do Google, o app acessa, nos canais do próprio dono:

  • dados básicos do canal (nome e identificador);
  • envio de vídeos (escopo youtube.upload);
  • leitura do canal (escopo youtube.readonly);
  • publicação de comentários nos próprios vídeos (escopo youtube.force-ssl).

3. Como usamos

Os dados servem só para publicar os vídeos agendados pelo dono e comentar neles. Não vendemos, alugamos nem compartilhamos dados com terceiros, e não usamos os dados para publicidade.

4. Armazenamento

Os tokens de acesso ficam criptografados no servidor do próprio dono. Nenhum dado de espectadores é coletado ou guardado.

5. Serviços do Google

O app usa os Serviços de API do YouTube. Ao usá-lo, você também aceita os Termos de Serviço do YouTube e a Política de Privacidade do Google. O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

6. Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Para pedir a exclusão dos tokens guardados, escreva para o contato abaixo.
